# 开源前检查与仓库关系

## 1. 仓库状态与来源

本项目基于 OOSEX GANG 的 [HackiOS kernel](https://github.com/oosexgang/hackios-xnu-kernel) 和 [HackiOS userland](https://github.com/oosexgang/hackios-xnu-userland)。三个仓库 README 均说明来源与职责，原有许可证及版权声明保留。

| 仓库 | 默认分支 | 当前可见性 | GitHub fork 关系 |
|---|---|---|---|
| `hackios-k90-port` | `main` | private | 顶层工作区 |
| `hackios-xnu-kernel` | `k90-port` | private | 独立仓库，包含上游历史 |
| `hackios-xnu-userland` | `k90-port` | private | 独立仓库，包含上游历史 |

## 2. 隐私检查与处理范围

检查覆盖三个仓库的 Git 跟踪文件、待提交文件、所有本地分支与标签可达的文件版本，以及提交作者和提交者信息。二进制文件检查可识别的明文标识，gzip 数据解压后检查；顶层仓库的桌面截图另做目视检查。详细扫描结果和历史备份保存在已忽略的本地目录。

| 内容 | 检查结果与处理 |
|---|---|
| 个人提交邮箱 | 三个仓库的作者／提交者记录中存在；按用户要求保留 |
| 设备序列号 | 顶层说明、fastboot 输出、操作脚本及 kernel 旧版暂存脚本中存在；当前命令改用环境变量，历史副本同步清理 |
| 本机用户名、项目位置和 NAS 路径 | 顶层文档及旧版本中存在；改为项目相对位置或备份目录变量 |
| 会话标识 | 经验文档和可复用 Prompt 中存在；固定标识清理，Prompt 由执行者填写来源链接 |
| 私钥与常见服务令牌 | 本次规则扫描未检出；扫描结果不能覆盖所有凭据格式和编码方式 |
| 测试密码与内网地址匹配 | userland 中的匹配来自未修改的上游测试与任务配置，经上游文件比较确认；未发现属于本机用户的配置 |
| 图片与二进制材料 | 顶层已跟踪截图未见个人账号内容或 PNG 文本／EXIF 元数据；固件及镜像来源仍需按分发范围单独审阅 |

运行脚本使用 `SER` 或 `ANDROID_SERIAL` 选择设备。设备备份、原始日志、缓存及历史备份继续保存在 Git 忽略目录，仓库内仅保存分析结论和必要示例。

## 3. 历史清理与协作

只清理当前文件无法移除旧提交中的标识。本次对含有个人标识的可达历史执行定向替换，保留提交邮箱、上游版权声明及干净的上游历史。重写会改变受影响提交及其后续提交的 ID；顶层历史中的 kernel 子模块指针同步映射到清理后的 commit。

远端更新使用带预期旧值的强制推送，避免覆盖期间出现的新提交。已有其他 checkout 在继续推送前需要重新同步清理后的分支；本地原始历史备份仅用于恢复。GitHub 的隐藏引用、缓存和其他克隆的副本不属于本地分支扫描范围，公开前仍需结合实际托管状态核对。

## 4. fork 关系的后续选择

GitHub 公开仓库的 fork 也必须公开，当前私有副本先完成隐私与分发内容检查，再处理关联。[GitHub fork 可见性规则](https://docs.github.com/en/pull-requests/reference/forks)。

GitHub 公共 REST 接口提供新建 fork，未提供把当前独立仓库直接指定父仓库的参数。相同 Git 历史本身不会生成 GitHub 的 fork 关系。[创建 fork API](https://docs.github.com/en/rest/repos/forks#create-a-fork)。

需要正式 fork 关系，可在发布阶段从原仓库创建一个新名称的 fork，再推送已清理的 `k90-port`，设置默认分支并核对标签和仓库设置。旧私有仓库可先保留，确认新仓库后再决定名称和引用迁移。这个流程会创建公开仓库，应放在开源确认之后；当前保持独立仓库也可以通过 README 和上游 remote 清楚说明来源。

## 5. 发布前剩余事项

本次保留私有可见性。顶层仓库尚未选择单独的许可证；kernel 和 userland 保留各自现有 `LICENSE`。预构建固件、设备提取资料及其他第三方文件的分发许可需要按实际发布内容核对，本次隐私扫描未代替逐项许可审阅。

公开前复查最终分支、标签、Git 历史、Git LFS／Release／Actions 等托管内容，并确认发布范围。具体提交 ID 和远端核对结果记录在本轮完成报告中。
