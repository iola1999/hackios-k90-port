## 3. 环容量（26 线实测）

每帧约 6.9 条 `tl: f`（全部是 `fence`）加 `tl: s`、`tl: v` 各一条，共约 8.9 行。环 13,531 行覆盖约 1,514 帧、约 41 秒，而帧流是 98 秒。预登记按 2,083 行算的 2.8% 与 92 秒对 26 线不成立。

## 4. 故障与低帧态是同一件事

`signal 11` 唯一行数与 `bad access` 唯一行数在每一轮逐个相等（4/4、8/8、13/13），高帧轮两者都是 0。低帧态是 `backboardd` 的 SIGSEGV 反复重启：八代 pid `38 → 83 → 101 → 125 → 142 → 157 → 172 → 182`，低帧轮每秒提交 4.1 次，高帧轮 232.5 次，差 57 倍。绘制慢是后果，不是原因。
